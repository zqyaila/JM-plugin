## 功能

- 🔎 **搜索（可翻页）** — `#jm搜索` 一个框自适应：关键词（标题/作者/标签）走站内搜索，纯数字 / `JM123456` / 链接直接跳转作品；支持页码与「上一页/下一页」翻页
- 📕 **详情** — `#jm详情` 看作者、标签、章节数、观看/图片/点赞统计、简介
- 📚 **章节** — `#jm章节` 列章节（信息卡片图）
- 📕 **加密 PDF 下载** — `#jm<数字>` / `#jmpdf` 把整本/单章漫画合成**加密 PDF**（双密码），并**持久化缓存**，转发到其他群免重复下载
- 🔥 **热门 / 随机 / 分类** — `#jm热门` `#jm随机` `#jm分类`
- 👤 **会员** — `#jm登录` / `#jm退出` / `#jm收藏` / `#jm历史`
- 🗑 **资源管理（主人）** — `#jm删除` / `#jm清缓存` / `#jm缓存` 管理缓存 PDF
- 🖥 **锅巴网页配置** — 通过锅巴面板可视化配置通用密码、每页条数等

### PDF 加密说明（双密码）

`#jm<数字>` 生成的 PDF 带**两个打开密码**，二选一即可打开：

```
密码 1（通用密码）= 插件配置里的 pdfPassword
密码 2（作品ID）  = 漫画的 JM 号
```

- **通用密码**：在锅巴面板或 `#jm密码 <新密码>` 设置，默认空。留空则 PDF 仅能用「作品ID」打开。
- **作品ID**：每个漫画唯一的 JM 号（如 `1480269`），天然不同，无需配置。
- 加密采用 PDF 标准安全处理器（RC4/AES-128，PDF 1.7），主流阅读器（Adobe、浏览器、WPS）都能正常打开并输入密码。

### 持久化缓存

下载过的 PDF 会缓存到插件目录 `data/pdfs/`，之后**在任何群/私聊**再次请求同一作品（同章节）会直接命中缓存、秒发，无需重新下载。

- 缓存索引在 `data/index.json`。
- 主人可用 `#jm缓存` 查看、`#jm删除 <JM号> [章节]` 删单个、`#jm清缓存` 清空全部。

## 安装

在 Yunzai 根目录执行，用 `git clone` 拉取插件：

```bash
cd Yunzai
git clone <仓库地址> ./plugins/jmreader-plugin/
```

> 将 `<仓库地址>` 替换为本项目的实际 Git 地址（GitHub / Gitee 等均可）。

然后进入插件目录安装依赖（图片打乱还原 + PDF 生成）：

```bash
cd plugins/jmreader-plugin
npm install
```

重启机器人，或使用 Yunzai 的热更新（`#更新` 后加载）。

### 更新插件

```bash
cd plugins/jmreader-plugin
git pull
npm install
```

> 依赖说明：核心协议（签名/加密/解密/主机发现）**只用 Node.js 内置模块**，零第三方依赖。
> - `sharp` — 图片打乱还原（像素级）与 PDF 页转码，必装才能正确还原打乱的页。
> - `@muhammara/wasm` — PDF 生成与加密（WebAssembly 实现，跨平台、无需原生编译）。

## 目录结构

```plaintext
jmreader-plugin/
├─ index.js          插件入口（注册全部命令）
├─ guoba.support.js  锅巴网页配置接入
└─ apps/
   ├─ jmcore.js      JMComic 协议核心（签名 / AES 解密 / 主机发现 / 打乱算法）
   ├─ jm.js          数据仓库层（类型化接口 + 图片下载还原 + PDF 生成）
   ├─ render.js      漫画风信息卡片渲染器（SVG→PNG）
   └─ store.js       持久化缓存层（data/ 目录 PDF 缓存读写）
```

## 实现原理

与 Kotlin 版 `app/src/main/kotlin/com/jm/reader/data/net/` 一一对应：

1. **主机发现** — 从 CDN 拉取加密服务器列表（AES 解密，key = `md5("diosfjckwpqpdfjkvnqQjsik")`），
   逐个用 `GET /setting` 探测，取第一个 `code:200` 的主机，失败回退内置主机。
2. **请求签名** — 每个请求带 `Tokenparam` = `<unixSecs>,<appVersion>`、
   `Token` = `md5("<unixSecs>185Hcomic3PAPP7R")`。
3. **响应加密** — `{ "code":200, "data":"<base64 AES-256-ECB>" }`，
   解密 key = `md5("<本次时间戳>185Hcomic3PAPP7R")`（必须用本次请求发送的时间戳）。
4. **图片打乱** — 阅读器按 `md5(专辑ID + 页码)` 计算切片数，重组倒序水平条带。

## 配置

本插件配置保存在 Yunzai 的 `config/jmreader.yaml`（首次运行自动生成）：

```yaml
pdfPassword: ''   # PDF 通用密码（userPassword），与作品ID（ownerPassword）构成双密码
pageSize: 10      # 列表每页显示条数（1-20）
imageQuality: 82  # PDF 内页 JPEG 压缩质量（0-100，预留）
```

可通过两种方式修改：

- **锅巴面板**（推荐）：装好 [guoba-plugin-next](https://github.com/cchanlan/guoba-plugin-next) 后，本插件配置会自动出现在锅巴面板里，可视化修改通用密码、每页条数等。
- **命令**：`#jm密码 <新密码>` 设置通用密码、`#jm密码 清空` 清空。

其余无需额外配置即可使用（主机自动发现）。如需调整：

- **接口语言**：默认 `TW`（繁体），在 `apps/jmcore.js` 里 `this.lang` 改为 `CN` 即简体。
- **图片主机**：默认自动从 `/setting` 获取，兜底 `cdn-msp3.jmdanjonproxy.vip`。

### 锅巴网页配置接入说明

`guoba.support.js` 暴露了 `supportGuoba()`，向锅巴面板提供以下配置项：

| 配置项 | 类型 | 说明 |
| --- | --- | --- |
| `pdfPassword` | Input | PDF 通用密码 |
| `pageSize` | InputNumber | 每页显示条数（1-20） |
| `imageQuality` | InputNumber | 图片压缩质量（0-100，预留） |

锅巴面板保存时，会通过全局钩子回写到 `config/jmreader.yaml` 并即时生效。

## 已知限制

- `sharp` / `@muhammara/wasm` 未安装时无法生成 PDF。
- 评论/签到/收藏管理等进阶接口已在 `apps/jm.js` 预留，命令层未全部接出，可按需扩展。
- 登录密码会出现在聊天记录里，请仅在私聊/可信环境使用。
- 整本漫画合成 PDF 会较大，发送大文件时可能受 QQ 群文件大小限制；建议单章下载，或分卷。
- 缓存不设过期时间（除非主人手动删除），长期使用会占用磁盘；可用 `#jm清缓存` 清理。
